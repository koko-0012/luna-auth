# Luna Auth for Fabric

Luna’s server-side authentication connector for Minecraft 1.20–1.20.1. See [installation, commands and build instructions](../README.md).

This is an EasyAuth-derived fork with outbound Luna pairing, Discord account verification and panel-driven authentication actions. Its mod ID remains `easyauth` for compatibility. Replace an existing EasyAuth/Violet Auth installation; never load two copies together.
